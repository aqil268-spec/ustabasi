Şirkətlər, serverlər, bazalar

Render API açarı yoxdur.

Şirkət yaratmaq üçün bu serverin Render ayarlarında RENDER_API_KEY və RENDER_OWNER_ID olmalıdır.

Yeni şirkət

Hər şirkət üçün Render-də 1 server və 1 PostgreSQL yaradılır. Ödənişli planlar Render hesabınızdan aylıq ödənilir. "free" server 15 dəq boş qalanda yatır — yalnız sınaq üçün.

Admin şifrəsini sıfırla

Yeni müvəqqəti şifrə yaradılır, server yenidən başlayır (1–3 dəq). Admin ilk girişdə öz şifrəsini yaradır.
